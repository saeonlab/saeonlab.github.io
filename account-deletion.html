파티나잇 계정 삭제 안내

파티나잇(PartyNight, 개발자 새온랩) 계정과 관련 데이터를 삭제하는 방법입니다.

1. 앱에서 바로 삭제하기

  1. 파티나잇 앱을 열고 로그인합니다.
  2. 오른쪽 위 계정 아이콘 → 설정으로 들어갑니다.
  3. 계정 삭제를 누르고 확인합니다.

삭제는 바로 처리되며 되돌릴 수 없습니다. 같은 이메일로는 탈퇴일로부터 1년 동안 다시 가입할 수 없습니다(부정 이용 방지).

2. 앱을 쓸 수 없을 때 이메일로 요청하기

saeonlab@gmail.com 으로 제목 「파티나잇 계정 삭제 요청」, 본문에 가입한 Google 또는 Apple 계정 이메일을 적어 보내 주세요. 본인 확인을 위해 가입 이메일로 보내 주셔야 합니다. 확인 후 지체 없이 삭제하고 결과를 회신합니다.

3. 삭제되는 데이터

  • 계정 정보(이메일, 닉네임, 계정 식별자), 생년월일, 포인트와 포인트 내역
  • 작성한 라이브 후기와 후기 사진
  • 찜한 매장, 매장 방문 확인 기록, 차단 목록
  • 업주 인증 신청 정보(사업자등록증 사본, 연락처)

4. 삭제 후에도 남는 데이터

매장 제보제보자 계정 식별자와 메모를 지우고 매장 이름·종류·지역·주소만 남김
